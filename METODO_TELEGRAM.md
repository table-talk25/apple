# 📱 Metodo Telegram - Installa APK Senza Problemi

Telegram **NON blocca gli APK** ed è il metodo più semplice!

---

## ✅ PASSI DA SEGUIRE

### **PASSO 1: Sul Mac - Apri Telegram Web**

1. **Apri il browser** (Chrome, Safari, ecc.)
2. **Vai su:** https://web.telegram.org
3. **Accedi** con il tuo numero di telefono
4. **Inserisci il codice** che ricevi via SMS

### **PASSO 2: Invia l'APK a Te Stesso**

1. **Cerca "Messaggi salvati"** o **"Saved Messages"** nella barra di ricerca
2. **Clicca** per aprire la chat con te stesso
3. **Trascina il file `app-debug.apk`** nella chat
   - Oppure clicca sull'icona della graffetta → Scegli file
   - Naviga fino a: `/Users/ele/TableTalk mEat Together - Apple/FRONTEND/client/android/app/build/outputs/apk/debug`
   - Seleziona `app-debug.apk`
4. **Invia** il file

### **PASSO 3: Sul Samsung - Scarica e Installa**

1. **Apri Telegram** sul Samsung
2. **Vai su "Messaggi salvati"** (icona in alto a sinistra)
3. **Trova il file APK** che ti sei inviato
4. **Tocca il file** → **Scarica**
5. **Quando finisce il download:**
   - Telegram ti chiederà se vuoi aprire il file
   - **Tocca "Apri"** o **"Installa"**

### **PASSO 4: Se Vedi Avviso Virus**

1. **Tocca "Installa comunque"** o **"Ignora"**
2. **Conferma l'installazione**

## 🆘 Se Telegram Non Funziona

### **Alternativa 1: WeTransfer**

1. **Vai su:** https://wetransfer.com
2. **Clicca "Get started"**
3. **Aggiungi il file** `app-debug.apk`
4. **Inserisci la tua email** (riceverai il link)
5. **Sul Samsung:** Apri il link dall'email → Scarica → Installa

### **Alternativa 2: Dropbox**

1. **Carica l'APK su Dropbox**
2. **Condividi il link** con te stesso
3. **Sul Samsung:** Apri il link → Scarica → Installa

### **Alternativa 3: Google Drive (come ZIP con Password)**

1. **Comprimi l'APK con password:**
   ```bash
   cd "/Users/ele/TableTalk mEat Together - Apple/FRONTEND/client/android/app/build/outputs/apk/debug"
   zip -e TableTalk-protected.zip app-debug.apk
   ```
   (Ti chiederà una password - scegline una semplice)

2. **Carica il ZIP su Google Drive**
3. **Sul Samsung:** Scarica → Estrai con password → Installa
